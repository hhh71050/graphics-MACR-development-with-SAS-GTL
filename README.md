# graphics-MACR-development-with-SAS-GTL
## usage
1. compile relative gtl template (run it in SAS, so a related Graphics.xx will be ready)
2. run an instance_xxPlot.sas, a macro that inspect data and extract dynamic var values that used in template
3. you may run code at the 'Example Macro Call' part of the instance_xxPlot.sas to see the layout
